EventMate is a full-stack college event management system designed to streamline event creation, registrations, and participation tracking.

### Key Features and Contributions:
- **Scalable Architecture**: Designed and developed scalable software solutions using Spring Boot and MySQL in a microservices-style architecture.
- **Performance Optimization**: Implemented API development best practices, query optimization, and caching to improve system performance.
- **Security & Deployment**: Developed production-ready features including JWT-based authentication and role-based access control, with deployment using Docker on AWS EC2.
- **Clean Code**: Followed clean coding practices to ensure reliability and maintainability.

Built using **Spring Boot**, **React**, and **MySQL**, the system follows REST API architecture and ensures scalable backend handling.

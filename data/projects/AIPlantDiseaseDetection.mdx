An end-to-end deep learning application that classifies plant leaf images into 39 disease categories using EfficientNet transfer learning.

### Key Contributions:
- Built the machine learning pipeline for preprocessing, data augmentation, training, validation, evaluation, and inference.
- Created a Flask application for image uploads and diagnosis, with confidence scores, top-k predictions, and disease-specific recommendations.

Built using **Python**, **PyTorch**, **EfficientNet**, **Flask**, **Pandas**, and **NumPy**.

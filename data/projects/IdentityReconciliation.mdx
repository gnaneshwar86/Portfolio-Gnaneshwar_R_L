Identity Reconciliation Backend is a system designed to identify and merge duplicate user records across datasets.

It ensures data consistency and avoids redundancy by applying intelligent matching logic.

Built with Spring Boot, Docker, and MySQL, the system is optimized for scalable backend processing.

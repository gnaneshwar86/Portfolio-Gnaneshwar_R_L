GKart is a full-stack online grocery shopping platform designed for seamless product browsing and purchasing.

It features category-based navigation, product listings, cart management, and responsive UI using Material UI.

The backend is powered by Spring Boot with REST APIs, while MySQL ensures efficient data storage.
